// Featured · Luau

Avalanche Escape for Brainrots

A round-based survival game where players outrun a rolling avalanche to save the brainrots. Built solo in Luau.

// SYSTEM 01

Avalanche physics

The avalanche is a server-authoritative wave that grows in speed and width as the round progresses. Chunks roll forward with deterministic noise so every player sees the same wall.

// SYSTEM 02

Brainrot rescue

Brainrots are NPCs scattered across the map. Players grab and carry them to escape zones for points; carrying one slows you down, so each pickup is a real decision under pressure.

// SYSTEM 03

Round & persistence

Round state machine handles intermission, countdown, active, and end phases. Player progress, unlocks, and stats are saved through DataStore with retry-and-merge on writes.

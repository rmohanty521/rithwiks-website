Bunny Merge Battles

An idle merge game: raise a swarm of bunnies, merge them into bigger ones, and send them after apples, bosses and new worlds. All clips are real gameplay with the live game UI.

Play on Roblox ↗
// Under the hood
  • Size-aware swarm layout. No fixed rings: a greedy packer walks outward ring by ring and gives each bunny the first spot that clears everyone already placed, so the formation grows with the count. Small bunnies lead, big ones fill the back, and the arc fans 160° behind you while walking, then closes into a full ring when you stop.
  • Surrounding enemies. On attack the biggest bunnies claim spots first, each spaced by the enemy's radius plus its own, filling the near side first. Returning bunnies keep their old slot, so a new arrival only shifts who it has to, and overlaps push apart by mass so small bunnies step aside.
  • Client-simulated swarms. The server only owns the roster (one encoded attribute). Every client simulates all swarms locally and turns toward a clicked enemy instantly, rolling back if the server says no.
  • Hits synced to animation. The server announces each swing 0.26s before damage, and clients start the headbutt clip early so its hit frame lands exactly on the damage, with slight random offsets so the swarm doesn't move in lockstep.
  • Merge choreography. All merges run off one shared render loop. Heavy merge storms degrade to a quick pop, and the first merge gets a 1.6× slow-mo scripted camera.
